# 🪔 DiwaliVerse — Web + Android App

DiwaliVerse is a festive React application with a native Android package powered by Capacitor. The web app and Android app share the same React UI and Supabase backend.

## Features

- Diwali home experience with festive animations and countdown.
- Interactive fireworks, virtual diyas, rangoli studio and home decorator.
- Greeting-card maker, photo booth, quiz, music and celebration activities.
- Account registration and login are required before entering the app.
- Discover registered members, send/accept/decline connection requests.
- Shared Diya rooms for connected users, with realtime room presence and activities.
- Supabase Auth sessions persist until the user logs out.
- Android app uses the bundled web build; it does not simply open the public website in a browser.

## Android app

### Build APK automatically

1. Open the repository's **Actions** tab.
2. Select **Android APK** and run it with **Run workflow**, or push a commit to `main`.
3. Open the completed workflow run and download the `DiwaliVerse-Android-debug` artifact.
4. Extract the artifact ZIP to get `app-debug.apk`, then install it on an Android test device.

For the Android build to connect to Supabase, add these repository Actions secrets:

- `VITE_SUPABASE_URL` — your Supabase project URL.
- `VITE_SUPABASE_ANON_KEY` — your Supabase publishable/anon key.

These are public client-side values. Never add a Supabase `service_role` key or secret key to the Android app, Vite variables, or GitHub Actions build.

### Open and build in Android Studio

Requirements: Node.js 22, Android Studio, Android SDK, and Java 21.

```bash
npm install
cp .env.example .env
# Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in .env
npm run android:init
npm run android:sync
npm run android:open
```

Android Studio opens the generated `android/` project. Use **Build → Build Bundle(s) / APK(s) → Build APK(s)** to create a debug APK.

After changing React code, run:

```bash
npm run android:sync
```

The `android/` directory is generated by Capacitor and is not committed to this repository. This keeps the source repo lightweight and reproducible; Android APKs are built by the included GitHub Actions workflow.

## Supabase setup

1. Create/open the Supabase project.
2. In **Authentication → Providers**, enable Email/Password sign-in.
3. In **SQL Editor**, run these files in order:
   - `supabase/schema.sql`
   - `supabase/social_connections.sql`
   - If you encounter the `room_members` RLS 42501 error, run `supabase/fix_room_members_rls.sql`.
4. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in your local `.env`, Vercel environment variables, and GitHub Actions secrets as applicable.

Do not disable Row Level Security to work around permission errors. The SQL policies are intended to limit access to authenticated users and their own/shared room data.

## Run the web app locally

```bash
npm install
cp .env.example .env
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Deploy the website

Import this repository into Vercel. Use:

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Environment variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
